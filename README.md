# Segundo Cérebro — Python e Automação de Dados

## Desafio DIO: Acelere sua aprendizagem com IA — Explore o poder do NotebookLM

## Sobre o projeto

Este projeto consiste na criação de um segundo cérebro digital utilizando o NotebookLM, com o objetivo de apoiar os estudos de Python, lógica de programação e automação de dados.

A ferramenta foi configurada com fontes de estudo confiáveis e instruções personalizadas para atuar como um tutor de aprendizagem, oferecendo explicações objetivas, exemplos práticos e referências às fontes utilizadas.

## Objetivo

Utilizar Inteligência Artificial como ferramenta de apoio ao aprendizado, organizando conhecimentos, consultando fontes confiáveis e facilitando a compreensão de conceitos fundamentais da programação Python.

## Ferramenta utilizada

- Google NotebookLM

## Fontes utilizadas

- [Documentação oficial do Python](https://docs.python.org/3/tutorial/)
- [Kaggle Learn — Python](https://www.kaggle.com/learn/python)
- [W3Schools — Python Tutorial](https://www.w3schools.com/python/)

## Configuração do segundo cérebro

O notebook foi configurado para:

- Explicar conceitos de programação de forma simples.
- Priorizar as fontes adicionadas.
- Apresentar exemplos práticos.
- Explicar códigos Python.
- Propor exercícios.
- Citar fontes utilizadas.
- Manter respostas curtas e objetivas.

## Teste realizado

Foi realizado um teste inicial solicitando ao NotebookLM uma explicação breve sobre Python, acompanhada de um exemplo de código e citações das fontes.

O resultado apresentou uma explicação introdutória, um exemplo utilizando `print()` e referências às fontes adicionadas.
